# 浏览器自动化消息助手监控程序

这是一个用于监控和管理浏览器自动化消息助手的 Python 程序。

## 功能特点

- 配置管理：设置消息模板、发送间隔、ID模式等
- ID管理：支持从文件导入ID或手动添加ID
- 实时监控：显示运行状态、消息计数、最后发送消息等
- 日志记录：记录所有操作和状态变化

## 安装说明

1. 确保已安装 Python 3.7 或更高版本
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

## 使用说明

1. 运行程序：
   ```bash
   python monitor.py
   ```

2. 配置选项卡：
   - 设置消息模板
   - 调整发送间隔
   - 配置ID匹配模式
   - 选择ID来源
   - 设置随机延迟范围

3. ID管理选项卡：
   - 导入ID文件（支持txt格式，每行一个ID）
   - 手动添加单个ID
   - 清空ID列表

4. 监控选项卡：
   - 查看运行状态
   - 开始/停止监控
   - 显示消息统计

5. 日志选项卡：
   - 查看操作日志
   - 清空日志
   - 保存日志到文件

## 文件说明

- `monitor.py`：主程序文件
- `requirements.txt`：依赖包列表
- `config.json`：配置文件（自动生成）
- `monitor.log`：日志文件（自动生成）

## 注意事项

1. 确保Chrome扩展已正确安装并启用
2. ID文件格式应为纯文本，每行一个ID
3. 配置文件会自动保存在程序目录下
4. 日志文件会记录所有操作和错误信息

## 常见问题

1. 如果程序无法启动，请检查：
   - Python版本是否正确
   - 依赖包是否安装完整
   - 是否有足够的系统权限

2. 如果无法导入ID文件，请检查：
   - 文件格式是否正确
   - 文件编码是否为UTF-8
   - 文件是否被其他程序占用

3. 如果监控状态不更新，请检查：
   - Chrome扩展是否正常运行
   - 网络连接是否正常
   - 日志中是否有错误信息
